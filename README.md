# 三维模型检查器

本地运行的三维模型检查网页(TypeScript + Three.js),用于检查模型内部结构和量尺寸。
无需后端、账号或任何在线服务,模型文件不离开本机。

## 功能

- **模型加载**:打开本地 `.glb` 模型;展示完整层级树;点击画面零件与层级列表双向同步高亮;支持隐藏、单独显示、恢复全部;多层嵌套 + 旋转/非等比缩放的零件也能正确选中;加载失败会提示原因并保留当前模型
- **视图操作**:轨道旋转/平移/缩放;一键适配可见模型;正视、侧视、俯视、透视视角预设(切换视角不清除剖切和测量状态);窗口缩放后画面比例与拾取位置保持正确
- **剖切**:X/Y/Z 三个方向独立开关,滑条调整位置,可反向;最多三个切面同时生效;模板缓冲封口(按轴着色: X 红 / Y 绿 / Z 蓝),与外表面明确区分;被切掉的部分不显示也不可选中;多零件、多切面互不串色
- **测量**:点选两个位置测距离,再选第三个点测角度(顶点在第二个点);毫米/厘米切换;画面标签与测量列表同步;隐藏或被剖掉的表面不能作为测量点;支持单条删除和全部清空
- **工程保存**:保存为 `.miproj.json`,内含模型本体(base64)、相机、零件显隐、剖切设置、单位、全部测量记录;重新打开完整恢复;坏文件/不支持的工程会说明原因且不破坏当前现场
- **导出**:当前画面导出 PNG(含剖切效果与测量标记,不改变视角);测量报告 JSON(模型名、单位、测量点坐标、距离/角度、剖切设置)
- **演示模型**:一键加载,含 5 个可分别选中的零件、空腔(底板通孔)、互相遮挡(盖板遮住销)、旋转 + 非等比缩放的嵌套零件(摆臂组)

## 安装与启动

```bash
npm install
npm run dev        # 开发模式, 打开终端提示的地址(默认 http://localhost:5173)
```

生产构建:

```bash
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 本地预览构建产物
```

## 测试

```bash
npm test           # 单元测试: 嵌套变换下的距离/角度、剖切选点限制、工程保存恢复、报告字段
npm run smoke      # 端到端冒烟: 用本机 Chrome 实际启动, 走一遍核心流程(需先 npm run build)
```

冒烟测试用的 GLB 固定文件已随仓库提供(`scripts/fixtures/demo.glb`);
如需重新生成: `node scripts/make-fixture.mjs`。

冒烟测试覆盖:页面加载、演示模型、层级选择同步、隐藏/恢复、视角切换后剖切保留、
已知尺寸核对(100mm 距离 + 90° 角度)、被剖点不可选、单位切换、工程保存/恢复、
坏工程文件处理、导出 PNG/报告、切换模型后旧测量清理。

## 演示模型已知尺寸(用于核对)

| 零件 | 尺寸 |
| --- | --- |
| 底板 BasePlate | 120 × 80 × 10 mm,中心通孔 Ø30 mm |
| 销 Pin | Ø16 × 30 mm,位于孔内(被盖板遮挡) |
| 盖板 CoverBlock | 60 × 40 × 20 mm,底面贴底板顶面 |
| 轴 Shaft | Ø10 mm,局部长 50 mm,经 2 倍缩放后世界长度 100 mm |
| 轴所在组 | 绕 Z 旋转 15°,非等比缩放 (1, 2, 1);父组绕 Y 旋转 30° |

核对示例:底板顶面 (-50,10,-30) → (50,10,-30) 距离为 100 mm,第三点 (50,10,30) 角度为 90°。

## 代码结构

```
src/
  main.ts        入口
  app.ts         应用装配:工具栏、模型加载、工程保存/恢复、导出
  viewer.ts      渲染器/相机/轨道控制/拾取/视角预设/适配
  clipping.ts    剖切管理(模板缓冲封口)
  measure.ts     测量点、连线、标签
  hierarchy.ts   层级树与节点路径
  demoModel.ts   内置演示模型
  measureMath.ts 距离/角度/单位换算(纯函数,可测)
  clipMath.ts    切面构造与裁剪点过滤(纯函数,可测)
  project.ts     工程序列化/校验(纯函数,可测)
  report.ts      测量报告生成(纯函数,可测)
test/            vitest 单元测试
scripts/smoke.mjs 端到端冒烟测试(puppeteer + 本机 Chrome)
```
